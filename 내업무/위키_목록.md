# 사내 위키에서 자주 보내는 페이지 (온보딩 담당이 모아 둔 목록)

| 위키 위치 | 내용 | 담당 |
|---|---|---|
| 총무 > 법인카드 | 팀장 결재를 받은 뒤 경영지원 신청서. 보통 사흘 | 경영지원 담당 |
| 총무 > 출장비 | 다녀온 뒤 일주일 안에 영수증 사진과 함께 경비 청구 | 경영지원 담당 |
| 총무 > 회의실 | 그룹웨어 > 자원 예약 > 회의실. 30분 단위 | 경영지원 담당 |
| 총무 > 명함 | 경영지원 신청서. 영문 표기를 함께 적는다 | 경영지원 담당 |
| IT > 비밀번호 | 그룹웨어 첫 화면 > 내 정보 > 비밀번호. 잊었으면 로그인 화면의 '비밀번호 찾기' | IT 지원 담당 |
| IT > 프린터 | 층마다 프린터 이름이 다르다. 프린터 옆에 붙은 이름을 IT 지원에 알린다 | IT 지원 담당 |
| IT > 메일 | 메일 > 설정 > 서명. 팀 양식은 사수에게 | 내 사수 |
| 인사 > 근태 | 그룹웨어 > 근태 > 출근. 늦을 것 같으면 팀 메신저 방에 먼저 남기고 사유를 적는다 | 인사 담당 |
| 인사 > 휴가 | 입사 달부터 쓴다. 그룹웨어 > 근태 > 휴가 신청, 팀장 결재 | 인사 담당 |
| 인사 > 필수 교육 | 입사 한 달 안에 두 과정. 교육 시스템에서 신청 | 인사 담당 |
